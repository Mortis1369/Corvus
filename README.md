Corvus is a Ventoy based recovery and technician tool. It was written in Rust.
The goal was to build off the idea created by Medicat: the tools you need, the software to catalogue them, and an installer to put it all together.
It is minimalistic by nature. That was the goal: to keep it as small as possible and still be useful.
The base package can be installed on something as small as a 64Gb flash drive (its just over 32Gb). With that, you would still have room for your .iso's for windows
and Linux.
